## 🚀 How to Deploy in 2 Minutes (Free)

### Option 1: GitHub Pages (Recommended)
1. Push this folder to your repository: `https://github.com/Hazil21/portfolio`
2. Go to **Settings** > **Pages**
3. Select `Branch: main` and `/ (root)` > Click **Save**
4. Your site will be live at `https://Hazil21.github.io/portfolio`!

### Option 2: Vercel / Netlify
1. Drag and drop the `hazil-portfolio` folder directly into [vercel.com](https://vercel.com) or [netlify.com](https://netlify.com).
2. Deployed instantly with a custom domain and SSL certificate!
